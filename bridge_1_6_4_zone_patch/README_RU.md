# Zonecraft Armor Zone & Tooltip Patch 1.0.0

Дополнение ставится **рядом** с рабочим мостом `Zonecraft-Stalker-Armor-Stats-Bridge-1.6.4-1.0.6-RUNTIME-MAPPING-FIX.jar`.

## Что делает

- `headProtection` реально влияет на попадания в верхнюю область головы.
- `limbProtection` реально влияет на попадания в ноги и боковые области рук.
- Для StalkerMod hitscan-оружия точка попадания вычисляется по лучу взгляда стрелка и bounding box цели.
- Для пуль-сущностей точка определяется по траектории снаряда.
- Значения не складываются второй раз с `bulletResistance`: патч применяет только поправку от общей пулестойкости к зональной.
- Удаляет дублирующиеся строки подсказки и устаревшие строки GLB-мода.

## Установка

1. Оставить рабочий мост версии 1.0.6 в `mods`.
2. Положить `Zonecraft-Armor-Zone-Tooltip-Patch-1.6.4-1.0.0.jar` в `mods`.
3. Полностью перезапустить игру.

## Конфиг

После первого запуска создаётся:

`config/zonecraftstalkerarmorzones.cfg`

По умолчанию скрываются только:

- `Общая защита`;
- `Скорость передвижения`.

Строки `Макс. здоровье` и `Сопротивление отбрасыванию` сохраняются, потому что они не дублируют характеристики StalkerMod. Чтобы убрать их тоже:

```properties
B:hideLegacyMaxHealth=true
B:hideLegacyKnockbackResistance=true
```

Все точные повторения строк удаляются автоматически:

```properties
B:deduplicateAllTooltipLines=true
```

Патч и основной мост автоматически перечитывают значения зональной защиты из `zonecraftstalkerarmorbridge.cfg`. Собственный конфиг патча также перечитывается автоматически без команды.

## Проверка зон

Для временной диагностики включить:

```properties
B:logDetectedHitZones=true
```

В логе появятся строки `HEAD` или `LIMB` и изменение фактического урона. После проверки параметр лучше вернуть в `false`.
