# Zonecraft NPC Stalker Compatibility Bridge 1.1.0

Отдельный обычный Forge-мод для Minecraft 1.6.4. Он ставится рядом с `stalcraftglb` и не изменяет `StalkerMod` или `CustomNPCs`.

## Исправления

- Возвращает серверный урон при стрельбе CustomNPC из настоящего `ru.stalcraft.items.ItemWeapon`.
- В `stalcraftglb 0.5.19` исходный снаряд CustomNPC отменяется перед созданием отражённой Stalker-пули. В проблемной сборке звук есть, но урон не проходит. Мост на минимальном приоритете восстанавливает отменённый штатный снаряд CustomNPC, поэтому столкновение и урон снова выполняются сервером.
- Повторно отрисовывает оружие `ru.stalcraft.items.ItemWeapon` в правой руке NPC после скрытия исходного тела GLB-костюмом.
- Использует текущую кость `ModelBiped/ModelNPCMale`, масштаб и позицию рендера NPC, включая экран редактора CustomNPCs.
- На сервере обнаруживает рядом Воронку/Black Hole/Carousel по классу блока, TileEntity или сущности.
- Восстанавливает притягивание и подъём для всех NPC без проверки GLB-костюма и без проверки фракции: дружественные, нейтральные и враждебные NPC обрабатываются одинаково.
- Игроков физика моста не затрагивает: для них остаётся штатная механика StalkerMod.

## Установка

1. Удалить старый `Zonecraft-NPC-GLB-Compatibility-Bridge-1.6.4-1.0.0.jar`, если он установлен.
2. Положить JAR версии 1.1.0 в папку `mods` рядом с:
   - исходным `stalker-01.jar`;
   - CustomNPCs 1.6.4;
   - STALCRAFT GLB Armor 0.5.19 или новее.
3. Полностью перезапустить Minecraft.
4. В слоте Projectile у стрелка должен оставаться предмет, чтобы AI CustomNPC запускал дальнюю атаку.

## Проверка

В логе при запуске должна появиться строка:

`[Zonecraft NPC Stalker Compat] 1.1.0 initialized.`

При восстановлении отменённого выстрела появляется:

`[Zonecraft NPC Stalker Compat] Restored CustomNPC projectile ...`

Не устанавливать старый патч, который заменял Java-файлы внутри StalkerMod.
