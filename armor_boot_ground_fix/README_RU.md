# Zonecraft Universal Armor Boot Ground Fix 1.0.0

Отдельный клиентский Forge-мост для Minecraft 1.6.4. Он не изменяет `stalkerarmor.jar`, `StalkerMod` или `CustomNPCs`.

## Что исправляет

- Автоматически определяет любой предмет `ru.stalcraft.glbarmor.item.ItemStalcraftSuit`.
- Приподнимает целиком GLB-рендер так, чтобы ботинки не проваливались в землю.
- Работает для всех зарегистрированных костюмов: старых и новых.
- Работает на игроках, CustomNPCs и других живых сущностях, которым надет GLB-костюм.
- Коррекция действует также на оружие, восстановленное NPC compatibility bridge, поэтому оружие и броня не расходятся по высоте.
- При приседании автоматически добавляет небольшую дополнительную компенсацию.

## Установка

1. Положить `Zonecraft-Universal-Armor-Boot-Ground-Fix-1.6.4-1.0.0.jar` в папку `mods`.
2. Не удалять `stalkerarmor.jar`.
3. Полностью перезапустить Minecraft.

## Конфиг

После первого запуска создаётся:

`config/zonecraft_armor_boot_ground_fix.properties`

Стандартные значения:

```properties
enabled=true
baseLiftBlocks=0.09375
sneakingExtraBlocks=0.03125
applyWhileAirborne=true
```

`0.0625` блока соответствует одному пикселю модели Minecraft. Стандартный подъём равен полутора пикселям и применяется одинаково ко всем костюмам.

Если ботинки конкретной модели всё ещё слегка погружены, увеличь `baseLiftBlocks`, например до `0.125`. Если они висят над землёй, уменьши до `0.0625`.
